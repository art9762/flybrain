# FlyBrain

## Новое: дуэль с мухой

Браузерный прототип по механике Buckshot Roulette: скрытые боевые/холостые патроны, восемь действий, предметы и обучение полного коннектома по числовому состоянию игры.

```sh
./run_roulette.sh
```

Запустите `./run_roulette.sh`, откройте http://127.0.0.1:8766 и нажмите **«Разбудить муху»**. При наличии `outputs/roulette-latest.npz` он загрузится автоматически; сейчас там сохранена модель после 14 000 суммарных обновлений. В панели обучения задаётся число дополнительных обновлений. Кнопка остановки прекращает обновления на ближайшей границе, затем завершаются оценка и сохранение. Во время игры веса заморожены. После работы остановите сервер сочетанием `Ctrl-C` в его окне. Подробности и результаты: [ROULETTE_BRIEF.md](ROULETTE_BRIEF.md).

## Комната привычек

Локальная 3D-песочница: муха исследует комнату с рилсами, кальяном, виски, вымышленным Claude Code и рулеткой. Вход мозга — изображение из глаз 64×48. Все 138 639 нейронов и 15 091 983 связей FlyWire v783 участвуют в вычислениях; обучение меняет часть существующих внутренних связей.

Это первая исследовательская версия. Механизм пластичности работает и проверен, но муха ещё не обучена надёжно пользоваться пятью предметами. Численные показатели и ограничения — в [проектном брифе](PROJECT_BRIEF.md).

## Открыть

```sh
./run_lab.sh
```

Перейдите на http://127.0.0.1:8765. Сервер слушает только этот компьютер. Нажмите **«Запустить»** или **«Один шаг»** — мозг загрузится при первом запуске. Ускорение выбирается до загрузки: автоматическое сравнение CPU/GPU, принудительный Metal или CPU. На Mac нужны PyTorch с MPS и обычный локальный терминал с доступом к GPU.

## Управление

- **Пауза / один шаг / скорость** — наблюдение и ускоренные пробы. Скорость ограничена временем расчёта, надпись 64× не гарантирует 64-кратного ускорения.
- **Вернуть в центр** — пауза и исходная позиция, без сброса обученных связей, времени, наград или завершённых занятий. Незавершённый жест отменяется; ещё не разыгранная ставка возвращается. Кратковременная активность и след недавних действий очищаются, чтобы награда не относилась к старой позиции.
- **Обучение** — выключение замораживает веса для оценки. Нейронная активность продолжает изменяться.
- **Хорошо / плохо** — подкрепляет недавние решения, должно следовать за шагом с включённым обучением.
- **Постоянная награда / с насыщением** — два режима; значения изменяются ползунками и кнопкой применения.
- **Штраф за пустую попытку** — по умолчанию −0,02 за недоступное действие, например использование предмета вне досягаемости. Значение 0 отключает штраф. Во время готового жеста штрафов нет; награда за его завершение относится к реальному начавшему действию, а не к игнорируемым выборам.
- **Рулетка** — 100 игровых фишек, ставка 5; ноль проигрывает красному и чёрному. Кнопка +100 пополняет банк без награды.
- **Сохранить мозг / загрузить** — `outputs/brain-latest.npz`; включает веса, нейронную активность, следы и генератор случайности. Комната в это сохранение не входит. Перед загрузкой нажмите паузу.

Муха учится выбирать действия и перемещаться. Жесты для просмотра, затяжки, глотка и нажатия пока готовые. Внешний 3D-вид более подробный, чем геометрия её зрения; окно «Её глазами» показывает фактические входные пиксели. Приложения, ролики и деньги вымышленные, работа не требует внешних аккаунтов.

## Проверить

```sh
PYTHONPATH=src python3 -m pytest -q
node --test tests/test_room_controls.mjs tests/test_room_events.mjs
PYTHONPATH=src python3 scripts/validate_runtime.py --help
```

Тренировка без открытого браузера (весь граф, только награды мира):

```sh
PYTHONPATH=src python3 scripts/train_room.py --backend mps --steps 2000 --max-seconds 120 --output-dir outputs/my-run
```

Каталог результата должен быть новым. Первый выполненный прогон лежит в `outputs/room-training`: 2000 шагов, одна награда за подтверждение Claude, банк 100. Это начальная траектория, не свидетельство освоения занятий. Сохранение `room-brain.npz` можно использовать как начальные веса следующего прогона через `--checkpoint`; комната тогда создаётся заново.

Отчёты реальных GPU-прогонов: `outputs/runtime_validation.json` и `outputs/runtime_validation_seed43.json`. В простом тесте двух изображений после 800 проб вероятность правильного действия выросла с 10,52% до 41,89% и с 12,79% до 54,76% при двух начальных состояниях. Это не проверка распознавания предметов или освоения комнаты. Ранняя историческая проверка комнаты насчитывала 56 пройденных тестов, включая Metal; актуальный статус общей регрессии и ограничения описан в [PROJECT_BRIEF.md](PROJECT_BRIEF.md).

Измеренный полный шаг мозга: около 25 мс GPU и 36 мс CPU. Проход по графу: около 6 и 11 мс. Это локальные измерения на M4 Pro, а не гарантия скорости на другом устройстве.

## Установка в отдельное окружение

На текущем Mac зависимости уже доступны. Для отдельной установки Python 3.11+:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[gpu,dev]'
PYTHONPATH=src .venv/bin/python -m uvicorn flybrain.lab:app --host 127.0.0.1 --port 8765
```

Three.js 0.170.0 сохранён в `web/vendor`, лицензия находится рядом. Данные уже скачаны в `data/`; источник, контрольные суммы и преобразования записаны в брифе. Научная модель — собственная упрощённая модель активности с искусственными сенсорными/моторными интерфейсами и ограниченной пластичностью, не полная биофизическая эмуляция мухи.

Старый прототип нейронной динамики оставлен в `flybrain.cli` и `flybrain.web`; он не используется новой комнатой.

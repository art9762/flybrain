# Historical neural-dynamics prototype README

Проект воплощённого обучающегося агента на основе коннектома мозга взрослой самки дрозофилы. Структура графа взята из публичного FlyWire v783; интеллект и обучение планируется связать с виртуальным телом и физическим миром. Подробная цель, критерии настоящего обучения и открытые решения описаны в [PROJECT_BRIEF.md](PROJECT_BRIEF.md).

Текущий код — только ранний инфраструктурный spike нейронной динамики. Он ещё не является виртуальной мухой и пока не умеет учиться.

## Что уже есть

- 138 639 нейронов и агрегированные направленные связи FlyWire v783.
- Знак связи из предсказанного нейромедиатора: возбуждение или торможение.
- Собственная дискретная LIF-подобная модель с настраиваемыми постоянными времени, порогом, рефрактерностью, усилением и внешним стимулом.
- Интерактивный запуск на достижимом подграфе до 20 000 нейронов.
- Запуск всего графа через CLI (`--neurons 0`).
- Локальный веб-интерфейс и JSON-результаты.

Важно: реальным является граф связей. Динамика пока является исследовательской гипотезой, а не полной биофизической эмуляцией или «цифровой живой мухой».

## Запуск

```bash
./run_lab.sh
```

Открыть: <http://127.0.0.1:8765>

Разовый эксперимент из терминала:

```bash
PYTHONPATH=src python3 -m flybrain.cli --neurons 5000 --duration-ms 250
```

Весь граф (может быть существенно медленнее):

```bash
PYTHONPATH=src python3 -m flybrain.cli --neurons 0 --duration-ms 100
```

## Данные и происхождение

Официальный релиз FlyWire v783 опубликован на Zenodo: <https://doi.org/10.5281/zenodo.10676866>. Сырые синапсы занимают около 9,5 ГБ. Для текущего движка используется агрегированный по парам нейронов снимок из репозитория `eonsystemspbc/fly-brain`:

- `data/flywire_connectivity_v783.parquet` — 15 091 983 пары до фильтра, SHA-256 `efeb23fb99098e9c390f6869969b2a121a2ee92c833cfc45ecb2c1d8e1af0347`.
- `data/flywire_neurons_v783.csv` — порядок и ID 138 639 нейронов, SHA-256 `52b0ac6094cd32c546f8d4c341e094376f48f4e791f8db9b166de5dff8199ea4`.

По умолчанию связи слабее пяти синапсов отбрасываются. Это ускоряет интерактивные опыты и явно регулируется параметром `minimum_synapses`.

## Модель v0.1

На каждом шаге мембранный потенциал и синаптический ток экспоненциально затухают. Входящие импульсы суммируются с весом `число_синапсов × знак × synaptic_gain`. При пересечении порога нейрон генерирует импульс, сбрасывается и входит в рефрактерный период. Выбранный нейрон получает прямой стимул в заданном временном окне.

Следующие научно важные улучшения: задержки по связям, разные параметры типов клеток, более аккуратное моделирование нейромедиаторов, сенсорные протоколы и сверка выходов с опубликованными экспериментами.
